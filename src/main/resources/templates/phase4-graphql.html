⚛️ Phase 4: GraphQL (Flexible Query & Batch DataLoader)

GraphQL cho phép Client tự định nghĩa cấu trúc dữ liệu cần nhận (tránh over-fetching và under-fetching). Module này tích hợp @BatchMapping giải quyết triệt để bài toán N+1 Query và MaxQueryDepthInstrumentation ngăn chặn tấn công DoS.

🚀 Mở GraphiQL Studio
💡
The Data Engineer Way: Khi truy vấn lồng products { reviews { ... } }, hệ thống KHÔNG gọi N câu query riêng lẻ. Cơ chế @BatchMapping gom toàn bộ IDs và chỉ thực hiện đúng 1 Batch Query duy nhất (sử dụng WHERE IN (...)) qua DataLoader pattern.

🛡️ Thông số Kỹ thuật & Bảo mật

  • • Endpoint chính: POST /graphql
  • • N+1 Resolver: @BatchMapping(typeName = "Product", field = "reviews")
  • • Max Query Depth: 8 tầng (Ngăn cyclic query loop)
  • • In-Memory Engine: ConcurrentHashMap (Zero lag, zero latency)
